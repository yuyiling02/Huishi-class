# 慧视课堂 - 科技感品牌套装 (Smart Cube Tech)

## 品牌寓意
“智慧魔方”是慧视课堂（Huishi Classroom）的核心品牌标志。
- **等距魔方结构**：象征稳定、多维和系统化，代表平台能够组织海量、复杂的三维教学资产。
- **三面发光模块**：代表多智能体协作（Planner、Executor、Evaluator）与三大核心能力（教学规划、手势交互、知识评估）。
- **中心光核**：寓意 AI 作为核心驱动力，为教学注入源源不断的智能生命力。
- **霓虹与网格材质**：传达深邃的科技感和极客精神，与“黑夜/星空”主题的界面视觉完美融合。

## 颜色规范
请遵循以下核心品牌色进行使用：
- **主品牌色 (Brand Blue)**: `#3D81E3` (深邃、稳重，用于左侧阴影/背景渐变)
- **核心高光色 (Cyan/Neon Blue)**: `#00D2FF` (灵动、耀眼，用于核心按钮、发光效果)
- **极光色 (Aurora Cyan)**: `#A4F4FD` (高光、渐变过渡，用于文字高光、魔方顶面)
- **深邃背景色 (Deep Dark)**: `#05070A` 至 `#0C0C0C` (极度沉浸，用于全息界面背景)

## 使用建议
1. **深色优先**：本套件是针对暗黑科技风格（Dark Mode / 苹果发布会风）量身定制，请优先使用 `lockup-dark.png` 和 `icon.png` 配合黑色/深蓝色背景。
2. **避免复杂底纹**：标志自带发光和玻璃质感，使用时背景应尽量保持纯净或只有极弱的星空/噪点纹理，不要使用杂乱的实景照片作为垫底。
3. **SVG 格式引用**：如果是 Web 前端开发，需要响应式或轻量化展示时，推荐直接引用 `mark.svg`（基于 CSS 和内联 SVG 编写的高效矢量简化版本）。
4. **留白规则**：请在标志四周保留至少等同于“中心光核”宽度的安全留白（Clear Space），确保品牌视觉不受干扰。

## 文件清单
- `icon.png`：带深色背景的原生预览版，适用于头像、启动图。
- `icon-transparent.png`：透明背景版，用于叠加在自定义深色星空背景上。
- `lockup-dark.png`：深色背景横版，左图右文（慧视课堂），最常用的组合。
- `lockup-light.png`：浅色背景横版，仅用于必须是白底的文档报告。
- `mark.svg`：纯矢量、超轻量的标志，可嵌入前端代码实现完美缩放。
- `brand-preview.png`：本套装的所有资产全局一览图。
