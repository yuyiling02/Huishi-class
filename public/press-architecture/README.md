# 慧视课堂新闻稿技术架构图

本目录包含 4 张新闻稿配图，每张均提供 SVG 母版和 PNG 导出版。

| 文件 | 建议用途 |
| --- | --- |
| `01-overall-architecture` | 总体介绍段落：说明系统从多模态输入、AI 编排到 3D 渲染与课堂反馈的完整闭环。 |
| `02-multi-agent-workflow` | AI 能力段落：说明理解规划 Agent、演示执行 Agent、学情评估 Agent 的协同流程。 |
| `03-interaction-data-flow` | 交互亮点段落：说明手势、语音、文件输入如何低延迟驱动 3D 课堂画面。 |
| `04-3d-rendering-pipeline` | 技术实现段落：说明 3D 模型从加载、结构增强到交互渲染的教学管线。 |

尺寸：2400 x 1350，16:9 横版。

SVG 适合后续改字和高清排版；PNG 适合直接插入新闻稿、公众号或演示文档。
